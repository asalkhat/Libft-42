## Description

Libft is a static library written in C that reimplements a set of standard C library functions, along with additional functions for strings, memory, numbers, file descriptors, and linked lists.

The goal of this project is to:

* Understand how C library functions work.
* Improve understanding of pointers and memory management.
* Practice working with strings and linked lists.
* Create a reusable library for future 42 projects.

## Instructions

`make` to compile the library.

`make clean` to remove all object files.

`make fclean` to remove all object files and the library.

`make re` to remove all object files and the library, then compile the library again.

The compiled library is called `libft.a`.
